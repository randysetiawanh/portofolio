Project Title
Kuffa - Fashion Store Web Application
Project Description
Kuffa is a fashion e-commerce web application developed as a final thesis project at STMIK Jayakarta. The goal was to build a functional online fashion store. My solution involved developing the platform using Python 3.9 and the Django Framework version 3.1. The completed project features a user-friendly dashboard, product detail pages, and a secure payment gateway integration using Midtrans to process online transactions effectively.

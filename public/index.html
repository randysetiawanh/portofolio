I started by breaking things

Before I shipped features I tested other people's. Six months at Vidio running release cycles on the mobile apps taught me what a defect looks like before a user finds it.

It is the reason my Laravel work carries verification steps in the user story, not just an acceptance line.

03RegressionEvery prior path re-run before a release is tagged.
